A fun, interactive quiz game built using Streamlit, inspired by the popular show Who Wants to Be a Millionaire?.
Players answer multiple-choice questions and win increasing prize amounts with each correct answer. The game ends when a wrong answer is selected.
 
Features:

Multiple-choice quiz with 11 questions
Prize money increases after each correct answer
Clean & interactive UI using Streamlit
Automatic game restart option
Real-time score updates
Uses st.session_state to track progress


How to Play:

1. You'll be shown one question at a time.

2. Choose your answer from the available options (A, B, C, D).

3. Click Submit to lock your answer.

4. If your answer is correct → you advance to the next question.

5. If wrong → the game ends, and your total winnings are shown.

6. Click Play Again to restart the game.


Technologies Used: Python, Streamlit, Session State for game logic, Simple list-based question bank
